Packages & updates

Game source and patch stay separate. Repair creates a fresh generation and preserves this profile's saves.

Effective baseline: 1.40b23. Current supported fan patch: 1.50.26. New upstream versions are not installed before compatibility verification. The official upstream download above stays separate from SGC release hosting.

Game imports are recognized by verified contents, not by their ZIP filename. Original folders and saves stay untouched. The optional 1.31 ZIP import supports offline CD upgrades; Steam does not need this prerequisite.

Launcher distribution

Updates use embedded signing keys. This build uses your configured GitHub release feed. Stage the signed update, then choose Apply staged update and restart. No replacement occurs during gameplay. An offline signed release folder remains optional.

Recovery & diagnostics

Removal only deactivates the environment. Files and saves remain retained. Rollback does not merge newer saves into older generations.
