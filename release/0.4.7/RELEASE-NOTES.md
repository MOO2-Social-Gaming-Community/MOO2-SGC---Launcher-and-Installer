# MOO2-SGC 0.4.7

Remember the selected profile across restarts; present historical Core rules accurately; show the actual engine/executable and transport command; integrate an explicit, game-independent Dopefish CONNECT/STATUS check. The diagnostic uses existing runtime verification and process locking and emits its own log/record without claiming connectivity success.

Includes the installer, updater, mod/environment manager, diagnostic helper and prepared signed packages for Windows x64, Linux x64, Intel macOS and Apple Silicon macOS. Existing signing identity and portable root C:\Games\MOO2-SGC are retained. Public packages contain no commercial game, DOSBox, RKERNEL binary or private key. PRSL, new Chat and future SGC Online remain disabled.

First test: select Community — standard (1.50.26), save the intended role and Dopefish service, reopen to check persistence, run the connection diagnostic, type EXIT, then prepare/verify and launch the game. The baseline is still independently available and remains the first-run default.

The release includes internal test evidence; Windows/macOS execution and live multiplayer were not performed in the build environment. This is a versioned development/testing release, not a claim of general availability or proven remote-service uptime.
